MECHANICS

Sandbox

A sandbox game is set up from three choices: a biome, a starting population and a map size. This page shows what each option holds in the game files. The settings are stored values; they have not been checked against a new sandbox game.

No preset starts with babies. The map generator is set to 15 construction tiles and 3 food sources per villager; the last two columns multiply those by the whole population. Whether kids and elders count, whether a construction tile is a square or a grid unit, and what counts as a food source, is decided in code that has not been read.

These are the stored map dimensions. The building grid stores two units per in-game square (a crop field is 2 × 2 units, one square); whether map sizes use the same units has not been checked, so they are shown as stored.

Biomes

Option labels are the settings' own names (Scarce, Average, Abundant; Small, Medium, Big); the game files hold no English text for them. Sandbox settings come from MapGenerationOptions and MapGenerator; biome lists from each biome's MapBiomeSettings.
