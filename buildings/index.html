Work schedules

The in-game clock dial shows a day face for the first half of each cycle and a night face for the second half, and the game names no hours. The standard crew therefore starts a tenth of a day before the dial turns to day and stops when it turns to night; the Clay Pit crew starts as the dial turns to day and works a tenth of a day into the night. One cycle is 300 seconds at normal speed, so a tenth of a day is 30 seconds.

Each workplace stores a shift as a start and end fraction of the day. A game day is 300 simulation seconds at normal speed, so the standard shift lasts 180 seconds and a tenth of a day is 30 seconds. Most workplaces run the same standard shift; a few start or finish later, which is why some crews are seen leaving for work after everyone else. Which clock hour the fraction 0 corresponds to has not been established.
