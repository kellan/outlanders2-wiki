This building’s steps include alternatives or gathering from the map, so no single ratio applies. See the production chain for the steps.

How production works

Workers repeat the recipe while inputs are available and stop when the building's output store is full. The output capacity of the Foragers' Hut has not been established. Capacity and recipe say nothing about speed: cycle time is not yet measured for any building.
