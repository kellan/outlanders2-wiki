Spoilers

This section contains reported-unreleased content and closely associated material whose release is unconfirmed. Names and details below may spoil future updates.

Placement here is editorial; it does not establish a release date. Other entries with unknown release status are not automatically treated as unreleased.

How we tell that something is unreleased

Every prefab in the game files carries a version gate (the MinGameVersion field on its key component). The game hides an object whose gate is higher than the running game version. The installed build reports version 30, and most prefabs store 0 or a version at or below it. An entry is marked confirmed unreleased only when its own prefab root stores a gate above the installed version; in this build that gate is 32. Entries are marked reported unreleased when the evidence is a maintainer or player report, and related, release unconfirmed when they merely belong with gated content (a scenario or biome that only exists for it) and have no gate of their own. Gates also give the update that added released content: building and resource infoboxes show it as “Added in update N”.
