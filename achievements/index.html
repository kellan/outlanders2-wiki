About this list

Names and goals are the game’s own text (version 31). The game builds its achievements in code rather than storing them as data, so what exactly counts is read from the wording: the code has separate kinds for running totals and for one level of making, eating or drinking, and gathering goods, which matches the goals that say “in a single town”. Achievements tied to content that is not out yet are left off.

Not known: whether the running totals include sandbox games and online challenges, and whether finishing the same level twice counts twice toward the “finish N levels” achievements.
