# Wetlands and Spookylands island art

The version 32 files have `MiniBiome-Swamp` (new in 32) and `MiniBiome-Halloween` island previews, but their pixels live in `resources.assets.resS`, which the research snapshot lacks (information-needed row added in PR 129). The local agent on the maintainer's Mac exported both from the installed game on 21 November 2026 (wiki branch `codex/research-answers`, commit 44ef292; `research/production-findings.json` key `biome_artwork_v32`; issue 10 comment 7062509146): `MiniBiome-Swamp` sprite 10637, 783 × 977, and `MiniBiome-Halloween` sprite 10349, 852 × 989.

Checked visually: the Wetlands island shows willows, cypresses and marsh channels; the Spookylands island shows dead trees and a tombstone. Both were resized to fit 800 × 800 like the other four previews (`im.thumbnail((800,800))`, alpha kept) and added as `assets/wiki-artwork/minibiome-swamp.png` and `minibiome-halloween.png`. `artwork.json` `biomes.Swamp` and `biomes.Halloween` point at them, so `icon()` (island previews only, PR 127) shows them on the biome pages and the home strip. The old `mapshape-valley-*` files stay in the repository but are no longer referenced. The information-needed row is removed.

The stale "Second game build for version history" row is removed too: versions 31 and 32 have both been compared (research docs/RELEASE-31-255.md and RELEASE-32-257.md), and pages carry Update 32 History rows. The local agent's backlog triage (research data/local-build-2026-11-21/README.md) pointed it out.
