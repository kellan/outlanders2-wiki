# Version 32 (build 257) data update

Source: research decode of `snapshots/macos-32-257` in a separate work directory, compared with version 31 (255) by `tools/release_diff.py` (data/release-32-257) and three review passes (content, walking, buildings). Path IDs move between builds, so the v30-based exporters were not rerun; changes are applied by name.

## What changed in the data

- **Plants (`decoded-mechanics.json` plants).** Removed every `Mushroom Spawner` that spawned `Mushroom Source`: in version 31 their GameObjects had `m_IsActive = false` (12 trees, Willow's second spawner, `_OrchardTreeBase`); version 32 deletes them with the Mushroom Source prefab. Willow's remaining spawner drops a Mushroom pile directly, so it is given a 1-Mushroom yield for display. Removed the Sticks Spawners on Apple, Banana, Berry Bush, Date Palm, Dragon Fruit, Fig, Grape, Nopal and Pomelo, inactive in both versions. Cypress and Willow get spread (2% / 3% a day), wild terrain (soil+sand / soil) and Cypress's chop condition.
- **Burrows.** `otherDropsText` now shows burrow spawners even though they carry a trap yield: Cypress (coypu, for the Swamp Trappers' Hut, tree can't be felled while trapped) and Winter Pine (rabbit, for the Trappers' Hut; confirmed in play on 26 Oct).
- **Stroganoff (`food_rates`).** Recipe per bowl: 0.5 cook of 17.42 s (1 fire + 2 StrogMix → DoubleStroganoff), automatic split, 0.25 Meat, 0.25 Mushroom, 0.1 Stick. 12.38 worker-s per bowl; 14.5 bowls/day with 1 worker, 20.7 with 2 (cook spot). The Mushroom supply keeps the version 31 picking time and is marked partial because the forage source no longer exists. Heat: fire lasts 0.12 days (was 0.1).
- **Biomes.** New research tool `tools/export_sandbox_biomes.py` → `data/sandbox-biomes-32-257.json`. Wetlands (Swamp) filled in; Spookylands updated (+9: Trading Post Evergreen, Bottle Factory, Winery, Dried Meat Shop, Fishing Dock, Boot Maker, Brewery, Scriptorium, Pendant Maker). `base_placeables` from MapGenerationOptions (22, incl. Road Brick and Upgraded Warehouse, new in 32) are now listed on biome pages and count in the comparisons and planter checks. The base Foresters' Hub ("Forester old") is a RemoteWorkspot planter of every forestry field, including Field HalloweenTree, so Dead Tree now shows a planter.
- **Walking.** `walking.sink_in_sand`: on Sand tiles with the scene's SinkInTheSand switch on, the slope factor is clamped to 0.3–0.7 (0.7 flat) and path cost is 1.5 (was 1.1). The name "shallow marshes" and the slow-down itself, in campaign and sandbox Wetlands, come from the developers' patch notes posted on the official Discord at release (shared by the maintainer, 20 Nov); the name is not in the decoded text tables. The ×0.7, the uphill limit and the path cost are from the code. Brick Road = Stone Road = ×2.15 in 30, 31 and 32.
- **History.** Update 32 rows (decoded-data) on the Stroganoff Cookhouse, Concoction Shop, Advanced Warehouse, Brick Road, Swamp Trappers' Hut, Cypress, Willow, Mushroom, Wetlands, Oona and her three levels.
- **Spoilers.** Holiday stays held: version 32 adds its full reward table, a Christmas style and three villagers, all gated to 32, but the server picks the running season and it has not been announced or seen. Arctic is still only a name.
- **Observations.** `stroganoff-two-cooking-spots` stays disputed with the version 32 explanation (one worker cooking spot plus the automatic split spot). `oona-update-live` now cites the decode.

## Older checks updated

Check 95 (biome lists), 71 and check-companion (Animal Hide outposts: the Evergreen outpost is now also offered in Spookylands) and 120 (mushroom and Stroganoff text) asserted version 30/31 facts that version 32 changed; they now assert the version 32 facts.

## Not done

Build times (Stroganoff 105 → 90 builder actions, Advanced Warehouse 4 spots × 15) are recorded in History only; the wiki has no build-time field. The Swamp Trappers' Hut build site uses the text key Building.TrapperHut, which has no text, so its label may be blank in game; unverified.

## Version numbering

The patch notes call this "game version 29", and the store text key for it is `Store.VersionWhatsNew.29` (Greek season is `.28`). The files' internal content gate is 32 (Greek 31). The wiki's "Added in Update N" labels use the internal gate, while History rows backdated from the App Store use the public number. This PR keeps the internal number to stay consistent with existing labels; whether to switch the labels to the public number is left to the maintainer.
