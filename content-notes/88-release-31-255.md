## Game version 31 (build 255) (2026-11-01)

The maintainer pushed a snapshot of the new release to the research repo. The full comparison is in research `docs/RELEASE-31-255.md`.

**What changed in the game files**
- The update adds a **Greek Tournament season** and nothing else that affects gameplay:
  - 14 rewards on the usual thresholds. The building rewards are Quarry, Two-Story House, Bakery, Fitness Park, Communal Plaza and Book Workshop.
  - A Greek town style, Greek villagers (gated at version 31) and Greek lighting for each biome.
  - A "New Town Style!" popup and two achievements: "Off the Menu" and "Speedrunner".
- The game's update notes say so too. Update 28's text now reads "a new Season for Tournament Mode with all-new rewards: Greek Season!". The Oona/Wetlands text moved to a new update 29.
- **Unchanged:** buildings, resources, recipes, levels, biomes and the existing reward tables. Every existing version gate is also unchanged, so Oona and the rest of her content stay gated at 32. That matches the maintainer's report that Oona did not release.
- **New unreleased names:** Holiday and Arctic seasons, each with a season name and a Game Center leaderboard but no rewards, style or villagers.

**Wiki changes**
- The Greek season's text entries and reward table are added to content/reference/world.json, so the Tournament page lists Greek with its rewards.
  - Greek is shown publicly because the game's own update notes announce it.
  - It is not marked current, because nobody has confirmed it has started.
- Holiday and Arctic are added to the text entries and withheld as spoilers ("related, release unconfirmed").
- **Spoiler reasons:**
  - The reasons for content gated at 32 now say the current game is version 31, and that the update notes list Oona's Wetlands as the next update.
  - The Egyptian and Imperial season reasons now name Greek as the newest season.
- content/reference/decoded-mechanics.json records current game version 31 and the new gate-31 Greek villagers.

**Not changed:** the "Game data v30 · build 254" label. Every gameplay value the wiki shows is identical in 31, so the label is still accurate for those pages.
