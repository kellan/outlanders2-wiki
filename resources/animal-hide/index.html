How it is made

Trading Outpost

Each Animal Hide: 1 Wheat

Smallest whole batch: 1 Wheat → 1 Animal Hide

Ratios from the production steps. The batch is the smallest run where every input comes out whole; nobody has timed this in play yet.

Trading Outpost

Each Animal Hide: 1.333 Glass Pane

Smallest whole batch: 4 Glass Pane → 3 Animal Hide

Ratios from the production steps. The batch is the smallest run where every input comes out whole; nobody has timed this in play yet.

Trading Outpost

Each Animal Hide: 2 Wheat

Smallest whole batch: 2 Wheat → 1 Animal Hide

Ratios from the production steps. The batch is the smallest run where every input comes out whole; nobody has timed this in play yet.
