CHALLENGE TYPE

Ranked challenges

An older challenge type scored on a leaderboard, still playable from the archive. The game files call it Leaderboard.

When it runs

No longer in the rotation, but still playable from the challenge archive. Before the rotation began, one Ranked level came out every two weeks from 3 Jul 2024 to 26 Mar 2025, together with one Chill and one Remix.
