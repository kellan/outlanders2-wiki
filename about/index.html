ABOUT THIS WIKI

Sources, data & artwork

An unofficial fan reference built from the installed Mac version of Outlanders 2.

Traceable by design

Building and resource pages link to source object IDs. Production chains retain every formula step used in their material balance. World entries retain localization keys and source text identifiers.

Recovered from game version 30, build 254. Packaged content can include unused definitions and alternate variants. UI observations are recorded separately from controlled gameplay tests, which remain pending.

The data was datamined, not decompiled: the game’s packaged asset files were read and their serialized configuration decoded, using type layouts recovered from the engine’s metadata. No game code or logic was reconstructed, which is why timing, yields and other runtime behaviour still need in-game verification.

In-game field guide

The game’s field guide supplies player-facing descriptions, displayed recipes, construction costs and worker slots. Bakery, Windmill, Sawmill and Greenhouse entries have been inspected, with screenshots linked from their pages. Scenario binaries provide exact objectives, build lists and need switches. Differences between displayed recipes and decoded process balances are retained in the research section; neither is treated as a measured production rate.

Original game artwork

The wiki uses 80 extracted game icons, 45 static leader portrait variants and six biome previews. Icons use unchanged original line sprites; portraits and biome images retain their original colors. Runtime color composition has not been reproduced. Some building symbols depict their output, as in the game UI.

Outlanders 2 and its artwork are credited to Pomelo Games. This wiki is unofficial and is not affiliated with or endorsed by the developer. Extracted artwork is not offered under an open-source code license.

Portable and static

The site has no server-side dependency. It can run on GitHub Pages at a repository URL or a custom domain. Every published URL has its own static page file, including readable entry paths such as /buildings/bakery/ and /food/bread/.

Scenario extraction

285 packaged maps decoded, including tests. All 438 objective records match their independent world copies. Build/plant lists and explicit villager-need flags are shown per scenario; absent legacy fields remain unspecified.

Remaining limits

  • Packaged data can contain unused content. Canonical content paths reduce but do not eliminate that possibility.
  • Formula balances are not production rates: staffing, animation, hauling, storage and availability affect throughput.
  • Construction totals are sums of distinct formula inputs and require checks for stage repetition and alternatives.
  • Tournament Mode (internally “FastMode”) supply-chain rules describe its level validator, not ordinary construction requirements.
  • No native method bodies or general AI/hauling logic were reconstructed.
  • ResourceVariationDatabase was not decoded; alternate resource logic is not fully resolved.
