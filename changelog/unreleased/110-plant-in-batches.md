Farm, Greenhouse, Orchard, Foresters' Hub and Oasis pages, and the Plants page, now advise marking a few fields or plots at a time: workers prepare every marked plot before planting any, so a big farm marked at once delays the first harvest (seen in play, and matches the game's work priorities) Orchards, Foresters' Hubs and Oases also raise each tree as a seedling first, which takes nearly half a game day; the fastest start is to mark a few plots, then let the workers start seedlings, which they plant as soon as each is ready (110).
