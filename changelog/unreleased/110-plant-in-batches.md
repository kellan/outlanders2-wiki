Farm, Greenhouse, Orchard, Foresters' Hub and Oasis pages, and the Plants page, now advise marking a few fields or plots at a time: workers prepare every marked plot before planting any, so a big farm marked at once delays the first harvest (seen in play, and matches the game's work priorities) Orchards, Foresters' Hubs and Oases also raise each tree as a seedling first, which takes nearly half a game day; with no plots to prepare they start seedlings early, so build the planter, let it fill its beds, then mark plots (110).
